# Ручная инструкция — Windows 10 / 11 (ПК + ноутбук)

Фикс **disconnect Lu4** без скриптов: отключить энергосбережение и HW-offload на том NIC, через который идёт игра.

| | |
|--|--|
| ОС | **Windows 10** и **Windows 11** — одни и те же шаги |
| ПК (кабель) | адаптер **Ethernet** (часто Realtek PCIe GbE) |
| Ноутбук (без кабеля) | адаптер **Wi‑Fi** / Wireless |
| Корень | NIC «засыпает» / offload ломает вход в мир `:9971` — **не** бан IP |
| Альтернатива | скрипты [Apply / Rollback](README.md) (то же самое автоматически) |

**Править только путь в игру.** Если играете по кабелю — трогайте Ethernet. Если только по Wi‑Fi — трогайте Wi‑Fi. Чужой адаптер не меняйте.

---

## 0. Перед правками

1. Закройте Lu4 / лаунчер.
2. Запомните, чем сидите в сети: кабель или Wi‑Fi.
3. (По желанию) Сфотографируйте вкладки **Управление питанием** и **Дополнительно** — так проще откатить вручную.

Рекомендуется скрипт `Apply-…` — он сам делает снимок «до». Ручной путь ниже — если нельзя/не хотите PowerShell.

---

## 1. Открыть свойства адаптера

### Windows 11

1. `Win` → введите **Параметры сети** → **Просмотр сетевых подключений**  
   или: **Параметры** → **Сеть и Интернет** → **Дополнительные параметры сети** → **Дополнительные параметры адаптера**.
2. Либо: `Win+R` → `ncpa.cpl` → Enter.

### Windows 10

1. **Параметры** → **Сеть и Интернет** → **Состояние** → **Настройка параметров адаптера**.
2. Либо: `Win+R` → `ncpa.cpl` → Enter.

В списке:

| Машина | Что выбрать |
|--------|-------------|
| **ПК с кабелем** | подключение с иконкой RJ‑45 / именем вроде `Ethernet`, `Realtek…` |
| **Ноутбук по Wi‑Fi** | `Wi‑Fi` / `Беспроводная сеть` / Intel/Realtek Wireless |

ПКМ по нужному подключению → **Свойства** → кнопка **Настроить…** (откроется окно драйвера NIC).

---

## 2. Вкладка «Управление питанием» (обязательно)

На вкладке **Управление питанием** / **Power Management**:

- [ ] Снять галку **Разрешить отключение этого устройства для экономии энергии**  
  (EN: *Allow the computer to turn off this device to save power*).

Нажмите **OK**. Это то же, что `PnPCapabilities=24` / `AllowComputerToTurnOffDevice=Disabled` в скрипте.

> Если вкладки нет — всё равно пройдите §3 (Advanced). На части Wi‑Fi драйверов галка спрятана в Advanced.

---

## 3A. ПК — Ethernet → вкладка «Дополнительно»

Вкладка **Дополнительно** / **Advanced**. Имена могут быть EN или RU — суть одна.

Для каждого пункта из таблицы: найти свойство → поставить значение **Отключено** / **Disabled** / **Выкл.** (где не указано иначе).

| Свойство (EN) | Часто по-русски | Цель |
|---------------|-----------------|------|
| Energy-Efficient Ethernet / EEE | Энергоэффективный Ethernet | **Отключено** |
| EEE Link Advertisement | Объявление / реклама EEE | **Отключено** |
| Green Ethernet | Зелёный / энергосберегающий Ethernet | **Отключено** |
| Selective Suspend | Выборочная приостановка | **Отключено** |
| Idle Power Down | Отключение питания в простое | **Отключено** |
| Large Send Offload v2 (IPv4) | Большой объём отправки v2 (IPv4) | **Отключено** |
| Large Send Offload v2 (IPv6) | … (IPv6) | **Отключено** |
| Recv / Receive Segment Coalescing (IPv4) | Объединение сегментов (IPv4) | **Отключено** |
| Recv Segment Coalescing (IPv6) | … (IPv6) | **Отключено** |
| TCP Checksum Offload (IPv4) | Проверка контрольной суммы TCP (IPv4) | **Отключено** |
| TCP Checksum Offload (IPv6) | … (IPv6) | **Отключено** |
| UDP Checksum Offload (IPv4/IPv6) | … UDP … | **Отключено** |
| IP Checksum Offload | … IP … | **Отключено** |
| ASPM / PCIe ASPM (если есть) | — | **Off / 0 / Disabled** |

Чего **нет в списке** у вашего INF — **пропустите** (не все Realtek/Intel показывают полный набор).

Нажмите **OK**. При кратком обрыве линка — нормально; подождите 5–10 с.

---

## 3B. Ноутбук — Wi‑Fi → вкладка «Дополнительно»

Тот же путь: `ncpa.cpl` → Wi‑Fi → **Свойства** → **Настроить…** → **Дополнительно**.

| Свойство (EN) | Часто по-русски | Цель |
|---------------|-----------------|------|
| Power Saving Mode / Power Save | Режим энергосбережения | **Отключено** или **Maximum Performance** / макс. производительность |
| Sleep on Disconnect / Device Sleep On Disconnect | Сон при отключении | **Отключено** |
| uAPSD / U-APSD | — | **Отключено** |
| Selective Suspend | Выборочная приостановка | **Отключено** |
| Idle Power Down | Отключение питания в простое | **Отключено** |
| Roaming Aggressiveness | Агрессивность роуминга | **Низкая** / Low / Medium-Low (не Highest) |
| LSO / RSC / Checksum Offload (если есть) | как у Ethernet | **Отключено** |

Плюс §2 (галка питания), если вкладка есть.

Идея та же: радио/NIC не уходит в сон на входе в мир `:9971`.

---

## 4. Проверка в Lu4

**E-Net OFF** (лаунчер без туннеля).

1. Запуск игры → фракция **Black**.
2. Список Servers → выбрать **Black** (или Recommended → Black).
3. Нажать **только OK** (не выбирать Black повторно).
4. Успех: экран **выбора персонажа**, без disconnect через ~2 с.

Дополнительно (по желанию, PowerShell):

```powershell
Get-NetTCPConnection -RemotePort 9971 -State Established -ErrorAction SilentlyContinue
```

Держится **≥ 20 с** → мир живой.

---

## 5. Если не помогло

1. Убедитесь, что правили **тот** адаптер, через который реально идёт трафик (кабель ≠ Wi‑Fi).
2. Перезагрузка ПК после смены Advanced — иногда нужна.
3. На ПК с кабелем **не обязательно** выключать Wi‑Fi; важны настройки Ethernet.
4. Сравните с автоматическим Apply:  
   `powershell -ExecutionPolicy Bypass -File .\Apply-Lu4EthernetNic.ps1`  
   ноутбук Wi‑Fi: добавьте `-Media WiFi`.

Откат вручную — вернуть значения из фото/заметок (§0). Скриптовый откат: `Rollback-Lu4EthernetNic.ps1` (только если до этого гоняли Apply и есть снимок).

---

## Краткая шпаргалка

```
ncpa.cpl
  → нужный адаптер (Ethernet ПК / Wi‑Fi ноут)
  → Свойства → Настроить…
  → Управление питанием: снять «разрешить отключение…»
  → Дополнительно: EEE / Green / Power Save / Sleep / LSO / RSC / checksum → Отключено
  → OK → проверить Lu4 (E-Net OFF → Black → OK → персы)
```
