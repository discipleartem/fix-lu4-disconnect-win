# Фикс disconnect Lu4 (Windows)

На Windows 10 и Windows 11 одно и то же.

**Проблема:** после выбора сервера игра выкидывает (disconnect).  
**Причина:** сетевая карта «засыпает» или режет пакеты. Это не бан IP.  
**Что делать:** отключить энергосбережение на том подключении, через которое играете.

- Играете по **кабелю** → настраивайте **Ethernet**
- Играете по **Wi‑Fi** → настраивайте **Wi‑Fi**
- Другие адаптеры не трогайте

Два способа: руками (ниже) или скриптом (в конце).

---

## Руками (5 минут)

### 1. Откройте список подключений

Нажмите `Win + R`, введите `ncpa.cpl`, Enter.

### 2. Откройте нужный адаптер

- ПК с кабелем → правый клик по **Ethernet** → **Свойства** → **Настроить…**
- Ноутбук по Wi‑Fi → правый клик по **Wi‑Fi** → **Свойства** → **Настроить…**

### 3. Управление питанием

Вкладка **Управление питанием** (Power Management):

Снимите галку  
**«Разрешить отключение этого устройства для экономии энергии»**.

Если вкладки нет — переходите к шагу 4.

### 4. Дополнительно — всё лишнее выключить

Вкладка **Дополнительно** (Advanced).

Найдите пункты ниже (если какого-то нет — пропустите) и поставьте **Отключено** / **Disabled**.

**Кабель (Ethernet):**

- Energy-Efficient Ethernet / EEE / Энергоэффективный Ethernet
- EEE Link Advertisement
- Green Ethernet / Зелёный Ethernet
- Selective Suspend / Выборочная приостановка
- Idle Power Down
- Large Send Offload (LSO) — IPv4 и IPv6
- Receive Segment Coalescing (RSC) — IPv4 и IPv6
- TCP / UDP / IP Checksum Offload
- ASPM (если есть) → Off

**Wi‑Fi (ноутбук):**

- Power Saving / Режим энергосбережения → **Отключено** или **Maximum Performance**
- Sleep on Disconnect / Сон при отключении
- uAPSD
- Selective Suspend
- Idle Power Down
- Roaming Aggressiveness → **Низкая** / Low
- LSO / RSC / Checksum Offload — если есть → **Отключено**

Нажмите **OK**. Интернет может на секунду моргнуть — это нормально.

### 5. Проверьте в игре

1. E-Net в лаунчере **выключен**
2. Зайдите в игру → фракция **Black**
3. В списке серверов выберите **Black** → нажмите **OK** один раз
4. Должен открыться выбор персонажа (без disconnect)

Не помогло? Перезагрузите ПК и проверьте ещё раз. Убедитесь, что правили именно то подключение, которым пользуетесь.

---

## Скриптом (если удобнее)

От имени администратора, из папки репозитория:

```powershell
# Авто: кабель, если есть; иначе Wi‑Fi
powershell -ExecutionPolicy Bypass -File .\Apply-Lu4EthernetNic.ps1

# Явно Wi‑Fi (ноутбук)
powershell -ExecutionPolicy Bypass -File .\Apply-Lu4EthernetNic.ps1 -Media WiFi

# Откат к настройкам до фикса
powershell -ExecutionPolicy Bypass -File .\Rollback-Lu4EthernetNic.ps1
```

Скрипт сам сохраняет снимок «как было» и меняет только нужные пункты. Откат без снимка не сработает.
